# Devansh Singh — Portfolio 🕷️

A personal portfolio site built around a dark, cinematic, Spider-Man-inspired visual style — because a resume on a webpage shouldn't be boring.

🌐 **Live:** [spidey-portfolio-kappa.vercel.app](https://spidey-portfolio-kappa.vercel.app)](https://lnkd.in/g878cuSQ)

## Overview

This isn't just a static resume — it's a showcase of full-stack builds, ML work, and design projects, wrapped in a UI that reflects how I actually like to work: clean interfaces, strong visuals, functional products.

## Features

- 💻 **Full-stack projects** — including a live, interactive demo of my Ticket Resale Platform's fraud-detection model (drag the sliders and watch the trust score update in real time)
- 🤖 **ML / data science work** — case studies with real metrics (e.g. XGBoost, Random Forest models)
- 🎨 **UI/UX & visual design** — brand and merch design work
- 🛠️ **Experience, skills, and education**
- 🕸️ Spider-Man-inspired visual details throughout (dark cinematic theme, web-particle background, custom cursor)

## Tech Stack

- HTML, CSS, JavaScript
- Deployed on [Vercel](https://vercel.com)
