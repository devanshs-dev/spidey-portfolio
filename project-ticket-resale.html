Ticket Resale Platform

A full-stack marketplace where fans resell event tickets safely — ML fraud scoring, real-time inventory sync, and QR-based verification, split across three independently deployed services.

ROLE
Solo Developer
TIMELINE
8 weeks
TYPE
Full-Stack Web App
STATUS
Live

The Problem

Ticket resale is rife with duplicate listings and fraud, and buyers have no way to verify a ticket is genuine before paying.

The Approach

  • Built a React + Tailwind frontend with a custom cinematic dark theme and Socket.io live updates
  • Designed a Node.js/Express API with JWT auth and a dual-database architecture — MongoDB Atlas for listings, PostgreSQL for analytics
  • Trained a fraud-detection model served through a separate Python Flask microservice
  • Added QR code generation per ticket so sellers and buyers can verify authenticity at handoff
  • Built an admin panel with Recharts dashboards for platform-wide analytics

The Outcome

Shipped as three independently deployed services — frontend on Vercel, backend and ML service on Render — with real-time listing updates and automated fraud flags reducing manual review.
