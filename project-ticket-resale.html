Ticket Resale Platform

A full-stack marketplace where fans resell event tickets safely — ML fraud scoring, real-time inventory sync, and QR-based verification, split across three independently deployed services.

ROLE
Solo Developer
TIMELINE
8 weeks
TYPE
Full-Stack Web App
STATUS
Live

The Problem

Ticket resale is rife with duplicate listings and fraud, and buyers have no way to verify a ticket is genuine before paying.

The Build

Built completely solo — every line of code, every deployment, every bug fixed at 2am. This project taught me more about how real systems are built than anything else I've worked on.

  • ML Fraud Detection — every listing is scored by a Scikit-learn model deployed as a Flask microservice. Fake listings get flagged before buyers ever see them.
  • Real-Time with Socket.io — when a ticket is bought, it disappears from every connected user's screen instantly. No refresh, no polling, pure WebSockets.
  • Two Databases — MongoDB Atlas for main app data, PostgreSQL on Supabase for analytics. Right tool for the right job.
  • JWT Auth + QR Verification — every purchase generates a unique QR code tied to the buyer, blocking screenshot fraud at handoff.
  • 3 Services Deployed in Production — React on Vercel (auto-deploys on every git push), Node.js API on Render, Flask ML service on Render.

The Outcome

Shipped as three independently deployed services with real-time listing updates and automated fraud flags reducing manual review. Open to feedback from the community — and open to SDE / full-stack roles.
