FIG. 05

Tic Tac Toe, Reconsidered

Tic-tac-toe scaled from 3×3 up to 5×5, with an unbeatable minimax opponent and a dark-mode interface.

ROLE
Solo Project
TIMELINE
1 week
TYPE
Web App / DSA
STATUS
Completed

The Problem

Wanted to implement minimax properly rather than just knowing it in theory — and make a version worth actually playing.

The Approach

  • Implemented minimax with alpha-beta pruning to keep 5×5 boards responsive
  • Generalized the win-condition logic across variable board sizes
  • Designed a dark UI with clear move animations and difficulty toggle

The Outcome

A genuinely unbeatable opponent at every board size, with pruning keeping response times instant even at 5×5.
