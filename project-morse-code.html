Morse Code Translator

A two-way Morse code encoder/decoder — lexical analysis in Flex, logic in C, compiled to WebAssembly and wired into a browser frontend.

ROLE
Solo Developer
TIMELINE
Feb 2025 – Apr 2025
TYPE
Systems / Web Tool
STATUS
Complete

The Problem

Most Morse code tools online are either a one-way encoder or a one-way decoder — few handle both directions cleanly, and even fewer expose the actual lexical parsing logic behind the translation instead of just doing a lookup-table swap.

The Approach

  • Used Flex (Lex) to perform lexical analysis on input text and Morse sequences, tokenizing characters and dot-dash patterns
  • Implemented the core encoding/decoding logic in C for fast, low-level processing of tokens
  • Compiled the C/Flex logic to WebAssembly so it runs directly in the browser without a backend server
  • Built a simple HTML/CSS/JavaScript frontend that calls into the WebAssembly module for real-time translation

The Outcome

A fully client-side Morse translator — no server round-trip needed for translation, since the C logic runs directly in-browser via WebAssembly. Supports both encoding (text → Morse) and decoding (Morse → text) through the same interface.
