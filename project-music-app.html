Music Recognition App

An interactive quiz where players race to guess songs from short, self-hosted audio clips.

ROLE
Solo Project
TIMELINE
2 weeks
TYPE
Web App
STATUS
Completed

The Problem

Wanted a lightweight, self-hosted alternative to song-guessing games that didn't depend on a third-party music API.

The Approach

  • Built a Node.js backend serving short, pre-clipped audio snippets on a timer
  • Implemented a scoring system rewarding faster correct guesses
  • Designed a minimal, distraction-free UI so the audio stays the focus

The Outcome

A playable, self-contained quiz game with no external API dependency or rate limits.
