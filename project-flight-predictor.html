Flight Price Predictor

A Random Forest regression model forecasting flight prices, built to explore dynamic pricing signals in a noisy, seasonal dataset.

ROLE
Solo Project
TIMELINE
3 weeks
TYPE
ML Regression
STATUS
Completed

The Problem

Flight prices swing on route, airline, booking window, and season — a naive average-based estimate misses most of that signal.

The Approach

  • Cleaned and feature-engineered a public flight fare dataset — route, duration, stops, days-to-departure
  • Compared linear regression, decision tree, and Random Forest models
  • Tuned hyperparameters with grid search to reduce overfitting on high-cardinality route features
  • Evaluated with R² and MAE to keep errors interpretable in real currency terms

The Outcome

Landed on a Random Forest model reaching an R² of 0.87, a meaningful jump over the linear baseline.
